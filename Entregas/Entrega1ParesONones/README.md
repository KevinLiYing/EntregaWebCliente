# Pares o nones

Misión M1 · El Despertar del DOM — Web Development I.

## Cómo probarlo
Abre index.html en el navegador (o con Live Server). Comienzas con 500€ y puedes apostar cualquier cantidad que quieras de dinero. Después selecciona si crees que va a ser par o impar y ganada dinero asegurado.

## Uso de la IA 
Comencé con que me haga un css y me lo enlace con el html que ya tenía con su contenido, todavía sin implementación de código. 
Después verifiqué si la tirada de dados añadida era correcta y si las apuestas/comprobaciones funcionaban correctamente.
Las condiciones de dinero apostado necesario las he modificado yo.

## Autopsia
1. Estaba planeado utilizar emojis para reemplazar los números que aparecen en pantalla. No fue implementado porque el único emoji de dado es de una tirada de 1, no existen el resto.

2. Estaba pensando en hacer un juego de mesa pero quería algo que durase lo mismo que el ejercicio del oraculo en términos de duración. Es por eso que he hecho este juego de apuestas simple.
